# 칸반보드 (Kanban Board)

Windows에서 상시 실행하는 **개인용 칸반보드 데스크톱 앱**.
같은 데이터를 두 가지 모드로 본다.

- **위젯 모드** — 바탕화면에 상주하는 작은 창. 테두리·제목표시줄 없이 보드만 보이고, 반투명 배경으로 바탕화면에 얹혀 있다.
- **풀보드 모드** — 컬럼과 카드를 드래그 앤 드롭하는 일반 칸반 화면.

클라우드 동기화 없이 **로컬 저장 전용**으로 완결된 버전(`v0.1.0`)이다. 데이터는 `%APPDATA%` 하위 JSON 파일 하나에 저장되고, 백업은 JSON 내보내기/가져오기로 한다.

---

## 주요 기능

### 두 가지 창, 하나의 데이터

- 풀보드 창(`main`)과 위젯 창(`widget`)이 **동일한 보드 데이터**를 공유한다.
- 한 창에서 카드를 추가·수정·이동하면 다른 창에 **즉시 반영**된다 (저장 → 이벤트 알림 → 다른 창이 다시 로드).
- 위젯은 풀보드보다 컴팩트한 레이아웃으로 같은 컬럼·카드를 보여준다.

### 카드

- 제목, 설명, 마감일, 태그(여러 개), 체크리스트, 카드별 배경색, 시작일(생성일).
- **더블클릭**으로 상세 편집 창을 연다 (풀보드·위젯 공통). 실수로 카드가 열리지 않도록 단일 클릭과 구분.
- 카드 앞면에서 바로:
  - 체크리스트 항목을 체크/해제·삭제 (편집 창을 열지 않고).
  - **마감일 배지를 클릭**하면 편집 창 대신 달력이 바로 열린다.
  - `×` 버튼으로 빠른 삭제 (확인 팝업).
- **시작일(생성일) 편집** — 기본값은 실제 생성 시각이지만, 편집 창에서 임의로 바꿀 수 있다.
- **태그 자동완성** — 이전에 쓴 태그를 입력 중에 드롭다운으로 추천 (앱 UI에 맞춘 커스텀 목록).
- 제목이 아주 길거나 공백 없이 이어져도 카드 폭 안에서 줄바꿈된다.

### 컬럼

- 컬럼 추가 / 이름 변경 / 삭제 (컬럼 삭제 시 그 안의 카드도 함께 삭제).
- 컬럼 하단 **빠른 추가 바** — 제목만 입력하고 Enter로 카드를 연속 추가 (풀보드 전용).
- 컬럼 우클릭 컨텍스트 메뉴로 위 동작 + 아래 기능에 접근.
- 넓은 화면에서는 컬럼이 한 줄에 나눠 채워지고, 좁아지면 아랫줄로 접힌다 (가로 스크롤 없음).

### 드래그 앤 드롭

- 카드를 컬럼 안에서 순서 변경, 컬럼 사이로 이동 (`@dnd-kit`).
- 드래그하는 동안 **실시간 미리보기**로 놓일 자리를 보여준다.
- 잘못 놓거나 드래그를 취소하면 **원위치로 되돌아간다**.

### 컬럼별 정렬

- 컬럼마다 정렬 기준을 지정: **수동(기본) / 시작일 / 마감일 / 태그**.
- 같은 기준을 다시 고르면 오름차순 ↔ 내림차순 토글. 마감일·태그 없는 카드는 항상 뒤로.
- 정렬은 **화면 표시만** 바꾼다 (카드의 실제 순서 데이터는 그대로). 정렬이 켜진 컬럼에서는 그룹 내 수동 재배치가 잠기고, 다른 컬럼으로 이동은 그대로 된다.

### 컬럼 카테고리 섹션 ("칸막이")

- 컬럼 안에 사용자가 만드는 **카테고리 섹션**으로 카드를 나눌 수 있다.
- 섹션 추가 / 이름 변경 / 삭제 / 접기. 섹션에 없는 카드는 "미분류"로 묶인다.
- 섹션을 삭제해도 그 안의 카드는 지워지지 않고 "미분류"로 남는다.
- 빈 섹션에도 카드를 드래그해 넣을 수 있다. 섹션 접힘 상태는 저장된다.

### 완료 카드 관리

- **'완료' 컬럼 지정** — 기본값은 제목이 "완료"인 컬럼. 우클릭 메뉴로 임의 컬럼을 완료 컬럼으로 지정/해제할 수 있다.
- 카드를 완료 컬럼으로 옮기면 **완료 시각이 기록**되고, 밖으로 빼면 (확인 후) 지워진다.
- 완료 컬럼은 평면 목록 대신 **완료한 날짜별 접이식 그룹**으로 표시된다 (오늘 그룹만 기본 펼침, "오늘"·"어제"는 그 말로 표기).
- 드래그로 완료 컬럼을 잠깐 지나가는 것만으로는 완료 처리되지 않는다 (드롭이 확정될 때만).

### 보관함 (아카이브)

- 완료 카드가 무한히 쌓이지 않도록, 삭제 대신 **보관함으로 치울 수 있다**.
- 보관 경로: 카드 우클릭 "보관" / 완료 날짜 그룹 헤더 "전체 보관" / 완료 후 N일 지나면 **자동 보관**.
- **보관함 패널** — 제목·태그로 검색, 보관일 역순 목록, 개별 **복원**(완료 컬럼 맨 아래로) / **영구 삭제**.
- 진입: 풀보드 헤더 `⋯` 메뉴 / 위젯 우클릭 메뉴.
- 보관 카드도 JSON 내보내기/가져오기에 포함된다.

### 마감일 강조

- 마감일 상태를 색으로 구분: **지남**(빨강) / **임박**(3일 이내, 주황) / 그 외(무채색).
- 위젯에서도 동일하게 강조돼, 작은 창에서도 급한 카드가 눈에 띈다.

### 백업 — JSON 내보내기 / 가져오기

- 클라우드 동기화가 없는 대신, 보드 전체(보관 카드 포함)를 **JSON 파일로 내보내고 다시 가져올 수 있다**.
- 풀보드 헤더 `⋯` 메뉴와 위젯 우클릭 메뉴 양쪽에 있다.
- 가져오기는 파일 형식을 검증한 뒤 보드를 통째로 교체한다.

### 상시 실행 · 시스템 통합

- **트레이 아이콘**
  - 좌클릭 — 풀보드 창 표시/숨김 토글.
  - 우클릭 메뉴 — 풀보드 표시/숨김 · 위젯 표시/숨김 · 위젯 위치/크기 조정 · 종료.
- **전역 단축키 `Ctrl+Alt+K`** — 어디서든 풀보드 창 토글.
- 풀보드 창의 `×`는 **종료가 아니라 숨김** (상시 실행, 트레이로 복귀).
- **바탕화면 고정** — 위젯은 평소 다른 창들 뒤(바탕화면 레벨)에 고정돼, 클릭해도 앞으로 튀어나오지 않는다.
- **위치/크기 조정 모드** — 트레이 메뉴 또는 조정 헤더의 **"여기 고정"** 버튼으로 껐다 켠다. 켜면 드래그로 옮기고 크기를 조절할 수 있고, 끄면 다시 바탕화면에 고정된다. 첫 실행 때 한 번은 자동으로 조정 모드로 뜬다.
- 창 위치·크기는 재시작해도 **기억된다**.
- **시작 시 자동 실행** 옵션 (위젯 우클릭 메뉴에서 토글, Windows 로그인 시 자동 시작).
- 변경은 300ms 디바운스로 묶어 **자동 저장**된다.

### 위젯 모양 설정

- 배경 불투명도, 배경색, 카드색, 글자색을 조정할 수 있다 (미지정 시 테마 기본색).

## 기술 스택

| 구분 | 사용 |
|---|---|
| 셸 | Tauri v2 (Rust) |
| 프론트엔드 | React 19 + TypeScript + Vite |
| 스타일 | Tailwind CSS v4 + shadcn/ui (Radix) |
| 상태 관리 | Zustand + immer |
| 드래그 앤 드롭 | `@dnd-kit/core`, `@dnd-kit/sortable` |
| 로컬 저장 | `tauri-plugin-store` (JSON, `%APPDATA%` 하위) |
| Tauri 플러그인 | `store`, `global-shortcut`, `window-state`, `dialog`, `autostart` |

프론트엔드 UI 로직은 특정 셸에 종속되지 않게 작성했다 (Tauri API는 `src/lib/` 데이터 접근 계층 뒤에 격리).

## 프로젝트 구조

```
src/
  components/
    board/     풀보드 모드 — 컬럼, 카드, DnD, 섹션, 정렬, 보관함, 각종 다이얼로그
    widget/    위젯 모드 — WidgetView, 위젯 설정 다이얼로그
    ui/        shadcn/ui 프리미티브 (button, dialog, input, context-menu ...)
  store/
    boardStore.ts   Zustand 스토어 (모든 보드 조작 액션 + 자동 저장/동기화 구독)
  lib/
    boardStorage.ts  영속화 계층 (plugin-store, 비-Tauri 환경은 localStorage 폴백)
    boardSync.ts     창 간 변경 알림 (Tauri 이벤트)
    boardIO.ts       JSON 내보내기/가져오기 + 형식 검증
    sortCards.ts     컬럼 정렬 comparator
    labels.ts        사용된 태그 수집 (자동완성용)
    date.ts          날짜 포맷 + 마감일 상태 분류
    autostart.ts     시작 시 자동 실행 토글 (개발 빌드에서는 무효화)
  types/board.ts     Board / Column / Card / ColumnSection / ColumnSort 타입
src-tauri/
  src/lib.rs         창 생성, 트레이, 전역 단축키, 바탕화면 고정, JSON 파일 IO
  tauri.conf.json    창 정의(main/widget), 번들(.msi) 설정
```

### 데이터 모델 요약

- `Card`(id, title, description?, dueDate?, labels[], checklist[], order, createdAt, completedAt?, sectionId?, archivedAt?, color?)를
  `Column`(id, title, cardIds[], sort?, sections[])이 id로 참조하고,
  `Board`(id, title, columns[], cards{}, doneColumnId?, archivedCards[], autoArchiveDays?)가 전체를 보유.
- 카드는 `cards` 맵에 id로 저장하고, **표시 순서는 `Column.cardIds` 배열**이 원본이다 (`Card.order`는 보조 필드).

## 개발 / 빌드

> `package.json` / `src-tauri/Cargo.toml`이 있어야 아래 명령을 쓸 수 있다.

```bash
# 개발 실행 (프론트 + Rust 셸 함께)
npm run tauri dev

# 프론트만 브라우저 미리보기 (Tauri API 미동작, UI만 빠르게 확인)
npm run dev

# 타입 체크 + 프론트 빌드
npm run build

# 정적 검사
npm run lint

# Windows 배포용 .msi 번들 생성
npm run tauri build
```

- `.msi` 산출물: `src-tauri/target/release/bundle/msi/칸반보드_0.1.0_x64_ko-KR.msi`
- 설치 위치: `C:\Program Files\칸반보드\kanban-board.exe`
- 서명이 없어 설치 시 Windows SmartScreen "알 수 없는 게시자" 경고가 나온다 (추가 정보 → 실행).

### 데이터 저장 위치

- 보드 데이터: `%APPDATA%\com.kanbanboard.app\board.json`
- 위젯 로컬 설정(불투명도·색·최초 위치 여부): 위젯 창의 `localStorage`

| Phase | 내용 |
|---|---|
| **0** | Tauri + React/TS/Vite 스캐폴딩, Tailwind/shadcn, always-on-top 빈 창, 트레이 토글 |
| **1** | 타입 + Zustand + `tauri-plugin-store` 로드/자동저장, 컬럼·카드 CRUD, `@dnd-kit` 순서 변경·컬럼 간 이동, 카드 상세 패널 |
| **2** | 위젯 창 UI, 위젯 ↔ 풀보드 전환(트레이 + `Ctrl+Alt+K`), 창 위치 기억, 창 간 실시간 동기화 |
| **3** | 마감 임박 강조, `autostart` 옵션, JSON 내보내기/가져오기, 카드 앞면 상호작용·더블클릭 열기 |
