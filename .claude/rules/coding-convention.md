# 코딩 컨벤션

## 언어
- 주석과 설명(코드 내 주석, 커밋 본문, PR 설명 등)은 **한글**로 작성한다.
- 변수명·함수명·타입명 등 코드 식별자는 **영어**로 작성한다.
- 복잡한 로직에는 "왜 이렇게 했는지"를 한글 주석으로 남긴다. 코드만 봐도
  알 수 있는 내용(무엇을 하는지)은 굳이 주석으로 반복하지 않는다.

## React / TypeScript
- 함수형 컴포넌트 + Hook만 사용한다 (클래스 컴포넌트 금지).
- TypeScript strict 모드를 유지하고, `any`는 피하고 명시적 타입을 정의한다.
- 비동기 처리는 `async`/`await`로 통일한다 (콜백·`.then()` 체이닝 지양).
- 상태 관리는 Zustand 스토어로 통일한다 (컴포넌트 로컬 상태와 전역 상태를 명확히 구분).
- 하나의 함수/컴포넌트는 하나의 책임만 갖도록 분리한다.
- 매직 넘버·하드코딩된 문자열은 상수로 분리한다.

## Rust (src-tauri)
- 가능한 한 공식 플러그인으로 해결하고, 커스텀 Rust 코드는 창 관리·트레이 등
  플랫폼 통합에 필요한 최소한으로 유지한다.
- 에러는 무시하지 않고 적절히 처리한다 (`unwrap()` 남용 금지, 사용자에게 영향 있는
  실패는 명확한 에러 메시지로 전달).

## 공통
- 클린 코드 원칙을 따르고, 읽기 쉽고 유지보수하기 쉬운 코드를 지향한다.
- 사용자 입력(카드 제목/설명 등)은 저장·렌더링 전에 적절히 검증·이스케이프한다.
- API 키 등 민감한 값이 생기면 하드코딩하지 않고 환경 변수로 분리한다.
